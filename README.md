# Medical Test Appointment System

## Project Overview

The Medical Test Appointment System is a web-based application designed to help patients schedule diagnostic medical tests easily and efficiently.

The system manages test appointments while considering test duration, room availability, available time slots, and appointment priorities.

## Features

- Patient registration and login
- View available medical tests
- Check available appointment slots
- Book medical test appointments
- Appointment scheduling
- Appointment priority management
- Room availability management
- Test duration management
- View appointment details
- Cancel appointments
- Admin dashboard
- Manage patients
- Manage medical tests
- Manage rooms and time slots

## Problem Statement

Manual scheduling of medical diagnostic tests can cause appointment conflicts, room allocation problems, and inefficient use of available time slots.

This system provides a computerized solution for scheduling medical tests while considering test duration, room availability, and appointment priorities.

## Objectives

- Reduce appointment scheduling conflicts
- Efficiently allocate rooms and time slots
- Make appointment booking easier
- Improve management of diagnostic tests
- Provide organized appointment information
